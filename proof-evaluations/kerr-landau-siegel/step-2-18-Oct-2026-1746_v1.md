### C.1 Lemma 1 from Davenport p. 89 (fills B4)

Write χ = (q/·), which is primitive of conductor \|q\| ≥ 3 (F13). Take real s = σ ∈ (1, 2), so t = 0, and Davenport's (3) gives 𝓛 = log\|q\| + log 2. Davenport's (2) says −L′/L(σ, χ) < c₂𝓛 − Σ_ρ Re 1/(σ − ρ). Each term Re 1/(σ − ρ) = (σ − Re ρ)/\|σ − ρ\|² is ≥ 0 (as Davenport notes on the same page). Discarding every term except ρ = β (a nontrivial zero, since β ∈ (0, 1)):

  −L′/L(σ, χ) < c₂ log(2\|q\|) − 1/(σ − β).

Davenport's unnumbered display on p. 89 gives −ζ′/ζ(σ) < 1/(σ − 1) + c₁ (F15). Add the two, and use −L′/L = Σ χ(n)Λ(n)n^{−σ} and −ζ′/ζ = Σ Λ(n)n^{−σ}:

  Σ_n (1 + χ(n)) Λ(n) n^{−σ} < c₁ + c₂ log(2\|q\|) + 1/(σ − 1) − 1/(σ − β).

The last two terms equal (1 − β)/((σ − 1)(σ − β)) ≤ (1 − β)/(σ − 1)², because σ − β > σ − 1. Every term on the left is ≥ 0, since χ is real and so 1 + χ(n) ∈ {0, 1, 2}. Keep only the primes p ≤ X with χ(p) = 1, each of which contributes 2 log p · p^{−σ}. Now take σ = 1 + 1/log X, which lies in (1, 2) because X ≥ 3 > e. For p ≤ X, p^{−σ} = p^{−1} · p^{−1/log X} ≥ e^{−1}/p. Therefore

  (2/e) Σ_{p≤X, χ(p)=1} (log p)/p < c₁ + c₂ log(2\|q\|) + (1 − β)(log X)²,

and the right side is ≪ log\|q\| + (1 − β)(log X)², because \|q\| ≥ 3. ∎

### C.2 The ring O (fills B5, for \|q\| > 8)

If q ≠ 8, then √q ∉ Q(√2), so [K : Q] = 4 and 1, √q, √2, √2√q are linearly independent over Q. Their Z-span M is closed under multiplication, because (√q)² = q, (√2)² = 2 and (√2√q)² = 2q all lie in Z, and the cross products stay in the span. M contains 1, √q and √2. So M = Z[√q, √2] = O, and the four elements form a Z-basis. All four are algebraic integers, so O lies in the ring of integers of K.

### C.3 The Frobenius congruences and (3), (4) (fills B7, B8)

Let p be odd with p ∤ q. Then (√q)^p = q^{(p−1)/2}√q. Euler's criterion gives q^{(p−1)/2} ≡ (q/p) (mod p), and for odd p ∤ q the Kronecker symbol equals the Legendre symbol, so (q/p) = χ(p). Hence (√q)^p − χ(p)√q = (q^{(p−1)/2} − χ(p))√q ∈ pZ·√q ⊂ pO. The same argument with 2 in place of q gives (√2)^p ≡ (2/p)√2. Then (√2√q)^p ≡ (2/p)χ(p)√2√q.

In the commutative ring O, (a + b + c + d)^p ≡ a^p + b^p + c^p + d^p (mod pO), because every multinomial coefficient other than the extreme ones is divisible by p. Also n^p ≡ n (mod p) for integers n. So

  θ_n^p ≡ n₁ + n₂χ(p)√q + n₃(2/p)√2 + n₄(2/p)χ(p)√(2q) (mod pO).

With χ(p) = −1:
- If (2/p) = 1, this is n₁ − n₂√q + n₃√2 − n₄√(2q) = σθ_n.
- If (2/p) = −1, this is n₁ − n₂√q − n₃√2 + n₄√(2q) = στθ_n, since στ sends √q ↦ −√q, √2 ↦ −√2 and √(2q) ↦ √(2q).

∎

### C.4 Lemma 2 (fills B9)

Write i = pe + v with 0 ≤ v < p. Then

  G_{i,j,k} = Σ_{t=0}^{e} C(e, t)(−1)^t x₁^{i−pt} x_ℓ^t x₂^j x₃^k.

The monomial for t has weighted degree (i − pt) + 8(j + k + t) = i + 8(j + k) − t(p − 8) ≤ D, because p > 8. So G_{i,j,k} ∈ L_D. The t = 0 term is x₁^i x₂^j x₃^k, with coefficient 1. Every other term has x₁ exponent i − pt < i.

Order the index set by decreasing x₁ exponent, breaking ties arbitrarily. In that order the matrix expressing the G's in terms of the monomials is triangular with ones on the diagonal and integer entries. Its inverse is also integral and unitriangular, so the G's form an O-basis of L_D. ∎

### C.5 Lemma 3 norm bound (fills B10, B11)

Let U = ⌊H/(8√\|q\|B^{i+j+k})⌋. For 0 ≤ u_t ≤ U, each embedding of c = u₁ + u₂√q + u₃√2 + u₄√(2q) has absolute value at most U(1 + √\|q\| + √2 + √2√\|q\|) = U(1 + √2)(1 + √\|q\|). For \|q\| ≥ 3, 1 + √\|q\| ≤ (1 + 1/√3)√\|q\|, so (1 + √2)(1 + √\|q\|) ≤ 3.81√\|q\| < 8√\|q\|. Hence ‖c‖B^{i+j+k} ≤ 8√\|q\| U B^{i+j+k} ≤ H.

Distinct (u₁, …, u₄) give distinct c by C.2. Distinct coefficient tuples give distinct f. Finally, (U + 1)⁴ > x⁴ where x = H/(8√\|q\|B^{i+j+k}). ∎

### C.6 Lemma 4 details (fills B12 to B15)

Take ℓ as stated. By (3) or (4), x₁^p − x_ℓ evaluated at (θ_n, σθ_n, στθ_n) lies in pO. Its e-th power lies in p^eO. The other factors lie in O, because σ and τ map O to O. So G_{i,j,k}(point) ∈ p^{⌊i/p⌋}O.

Since i ≤ D, ⌊i/p⌋ ≤ ⌊D/p⌋ ≤ k_p. Changing a coordinate c by an element of p^{k_p−⌊i/p⌋}O therefore changes f(point) by an element of p^{k_p}O.

O ≅ Z⁴ as a group, so \|O/mO\| = m⁴. Since P = Π p^{k_p} with distinct primes, the Chinese remainder theorem for Z, tensored with the free Z-module O, gives O/PO ≅ Π_p O/p^{k_p}O. The map sending f to its vector modulo PO factors injectively through the product of its vectors modulo each p^{k_p}O. So the count is at most the product of the counts. ∎

### C.7 The pigeonhole inequality (fills B16 to B19)

There are more polynomials than residue vectors if (P/(32r√\|q\|))^{4r} B^{−4W} ≥ P^{4r} Π_p p^{−4E_p}. Take logarithms and divide by 4. Then 4r log P cancels, and the condition becomes Σ_p E_p log p ≥ W log B + r log(32r√\|q\|). This is (11), with ≥ in place of >. The strict inequality in Lemma 3 makes either form enough.

The remaining bounds:
- ‖F‖_B ≤ 2H, by the triangle inequality in each embedding.
- ‖θ_n‖ ≤ (N − 1)(1 + √2)(1 + √\|q\|) < B, by C.5.
- ‖σθ_n‖ = ‖στθ_n‖ = ‖θ_n‖, because σ and τ permute the four embeddings.
- In each embedding, \|F(point)\| ≤ Σ ‖c‖B^{i+j+k} ≤ r · 2H = P/2.
- For 0 ≠ α = Pβ with β ∈ O: N(α) = P⁴N(β), with N(β) ∈ Z \ {0} because β is a nonzero algebraic integer. So \|N(α)\| ≥ P⁴. But \|N(α)\| = Π_t \|α^{(t)}\| ≤ (P/2)⁴. Contradiction, so α = 0.

∎

### C.8 The asymptotics and "(9) implies (11)" (fills B20, B21)

Let R_D = {(i, j, k) ∈ Z³_{≥0} : i + 8(j + k) ≤ D}. Put s = j + k. The number of pairs (j, k) with j + k = s is s + 1, and for each s, i runs over 0, …, D − 8s.

The continuous analogues, with area element s ds for (j, k):
- **r:** ∫₀^{D/8} s(D − 8s) ds = D³/128 − D³/192 = **D³/384**.
- **Σ i:** ∫₀^{D/8} s(D − 8s)²/2 ds = **D⁴/1536**.
- **Σ (j + k):** ∫₀^{D/8} s²(D − 8s) ds = D⁴/1536 − D⁴/2048 = **D⁴/6144**.
- **W = Σ i + Σ (j + k):** 4D⁴/6144 + D⁴/6144 = **5D⁴/6144**.

All by hand. The lattice sums differ from these integrals by O(D²) for r and O(D³) for the degree-one sums. Each is a sum of a polynomial of degree d ≤ 1 over the lattice points of the dilate D·R₁ of a fixed polytope, and the error is bounded by the boundary contribution, O(D^{d+2}). Step 3 checks these exactly.

**E_p.** Since 0 ≤ i/p − ⌊i/p⌋ < 1, E_p = (1/p)Σ i − θ_p r with 0 ≤ θ_p < 1. So E_p = D⁴/(1536p) + O(D³), uniformly in p.

**(9) implies (11).** Multiply E_p by log p and sum over S. The error is ≪ D³ Σ_{p≤Q} log p ≪ D³Q by Chebyshev. So

  Σ E_p log p ≥ (D⁴/1536)(13/10) log B − C D³Q.

The right side of (11) is at most

  (D⁴/1536)(5/4) log B + C D³ log B + C D³ log(32r√\|q\|).

The difference is at least

  (D⁴/1536)(1/20) log B − C D³Q − C D³ log B − C D³ log(32r√\|q\|).

Since B ≥ N, the first term is ≥ D⁴ log N / 30720. Against it:
- D³Q = D⁴/(log N)².
- log B ≤ 2 log N + 3.
- log(32r√\|q\|) ≪ log D + log\|q\| ≪ log N, because D ≤ N^{4/3} and \|q\| ≤ N for γ ≥ 1.

Every error term is o(D⁴ log N) with constants that do not involve γ. So (11) holds for N ≥ N₀, with N₀ absolute. ∎

### C.9 Mertens and Lemma 1, and the decisive inequality (fills B26 to B28)

**Order of choices.** Let C₁ be the constant in Lemma 1. Fix the integer γ ≥ 90(C₁ + 2). Then fix ε = 1/(160 C₁ γ). Then take \|q\| ≥ q₀(γ), large enough for every "N large" condition below. Suppose (1 − β)log\|q\| < ε. Put ℒ = log\|q\|, so log N = γℒ.

**Lower bound for the sum over S.** Mertens gives Σ_{p≤Q} (log p)/p ≥ log Q − C_M. The primes p ≤ Q not in S fall into three groups:
- p ≤ 8: they contribute less than 2.
- p \| q with p > 8: they contribute at most Σ_{p\|q} log p ≤ ℒ.
- χ(p) = 1 (p ∤ 2q): by Lemma 1 with X = Q ≥ 3, they contribute at most C₁(ℒ + (1 − β)(log Q)²).

Since Q ≤ D < N^{4/3}, (log Q)² < (16/9)γ²ℒ². So (1 − β)(log Q)² < (16/9)εγ²ℒ = (16/9)εγ log N.

From D ≥ ½((N − 1)/3)^{4/3} − 1, log Q ≥ (4/3)log N − 2 log log N − C. Therefore

  Σ_{p∈S} (log p)/p ≥ log N [4/3 − (1 + C₁)/γ − (16/9)C₁εγ] − 2 log log N − C′.

**The target.** (13/10) log B = log N [13/10 + 13/(20γ)] + (13/10)log 8.

**Comparison.** (9) holds when

  log N [1/30 − (1 + C₁ + 13/20)/γ − (16/9)C₁εγ] > 2 log log N + C″.

With the choices above:
- (1 + C₁ + 13/20)/γ ≤ 1/90.
- (16/9)C₁εγ = 16/1440 = 1/90.

So the bracket is at least 1/30 − 2/90 = 1/90. The inequality then holds for N large, that is, for \|q\| ≥ q₀(γ). ∎

### C.10 The vectors, the determinant and the kernel (fills B29 to B32)

Fix an embedding K ↪ C, with √(2q) := √2√q. Write a = √q and b = √2. By the definitions of σ and στ, (θ_n, σθ_n, στθ_n) = n₁γ₁ + n₂γ₂ + n₃γ₃ + n₄γ₄, with γ₁ = (1, 1, 1), γ₂ = (a, −a, −a), γ₃ = (b, b, −b) and γ₄ = (ab, −ab, ab).

**Determinant.** det[γ₁; γ₂; γ₃] = 1·(ab + ab) − 1·(−ab + ab) + 1·(ab + ab) = 4ab = 4√(2q) ≠ 0. So π has rank 3, and ker π has dimension 1.

**Kernel.** π(v) = ab·γ₁ + b·γ₂ − a·γ₃ − γ₄. Coordinate by coordinate:
- ab + ab − ab − ab = 0;
- ab − ab − ab + ab = 0;
- ab − ab + ab − ab = 0.

So ker π = Cv.

**No rational subspace contains ker π.** If ker π lay in a proper subspace spanned by rational vectors, that subspace would lie in a hyperplane Σ aᵢxᵢ = 0 with a ∈ Q⁴ \ {0}, and then Σ aᵢvᵢ = 0. That contradicts the Q-independence of 1, √q, √2, √(2q), which holds for q ≠ 8 by C.2.

**Final contradiction.** F ∈ L_D has total degree at most D, because i + j + k ≤ i + 8(j + k) ≤ D. Its image under the embedding is a nonzero complex polynomial of the same degree. With M = N − 1 ≥ 3 and µ ≥ 4/3, (M/3)^µ ≥ (M/3)^{4/3} > D. Since rank Γ = 4, γ₁, …, γ₄ is a basis of Γ, which is the hypothesis Masser's Theorem 1 needs (Step 4 to confirm). ∎

### C.11 Small \|q\| (fills B2)

For each of the finitely many fundamental discriminants with \|q\| < q₀(γ), L(s, χ) is entire and not identically zero, so its zeros in [0, 1] are finite in number (F14). Also L(1, χ) ≠ 0 (F14), so every real zero satisfies β < 1. Hence c_small := min over these q and their real zeros in (0, 1) of (1 − β)log\|q\| is positive, or there are no such zeros. Take c = min(ε, c_small).

Whether c can be computed (the effectivity question) depends on whether C₁, C_M, the Chebyshev constant and N₀ are explicit, and on a finite computation for small q. That question is reserved for Step 5. ∎
