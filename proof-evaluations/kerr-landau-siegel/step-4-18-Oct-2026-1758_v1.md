## 1. Masser [5] against Kerr's Lemma 6 (Step 2, item B22)

### 1.1 What Masser states

Masser, p. 82 (checked against the page image):

> Let Γ be a non-trivial finitely generated additive subgroup of Cⁿ. Let l ≥ 1 be its rank, and for 1 ≤ r ≤ n let l_r be the maximum rank of any subgroup Γ′ of Γ for which there is a subspace V of Cⁿ of dimension r with v · γ = 0 for all v in V and all γ in Γ′. Define µ(Γ) = min_{1≤r≤n} (l − l_r)/r. Let γ₁, …, γ_l be **basis elements** of Γ, and let Γ(N) be the set of points n₁γ₁ + ⋯ + n_lγ_l with non-negative integers nᵢ not exceeding N.
>
> **Theorem 1.** For real N ≥ 0 and D ≥ 1, let P be a non-zero polynomial of total degree at most D such that P(γ) = 0 for all γ in Γ(N). Then D ≥ (N/n)^µ.

This is a paraphrase. The symbols are Masser's.

### 1.2 Comparison with Kerr's Lemma 6

| Point | Masser, Theorem 1 | Kerr, Lemma 6 | Finding |
|---|---|---|---|
| (a) Points | γ₁, …, γ_l are a **basis** of Γ, so l = rank Γ | γ₁, …, γ_s are **any generators** of Γ | **Kerr's statement is broader than the source.** |
| (b) Exponent | µ = min_r (l − l_r)/r, defined through annihilators | µ = min over proper L of rank(Γ/(Γ ∩ L))/(n − dim L) | **Equivalent** (my proof in 1.3). Kerr never shows this. |
| (c) Range | Non-negative integers not exceeding N, with N ≥ 0 real | Integers 0 ≤ mⱼ ≤ M, with M ≥ 1 an integer | Kerr's is a special case. No issue. |
| (d) Degree | "Total degree at most D," with D ≥ 1 real; conclusion D ≥ (N/n)^µ | Conclusion deg F ≥ (M/n)^µ | Take D = deg F. This needs deg F ≥ 1, which holds because a nonzero constant cannot vanish at the point 0 (all mⱼ = 0). Kerr leaves this unsaid. Routine. |
| (e) Non-triviality | Γ non-trivial | Not assumed | If every γⱼ = 0, then µ = 0 and the bound deg F ≥ 1 holds trivially. No issue. |
| (f) Scalar product | The bilinear form x · y = Σ xᵢyᵢ (as Masser's proof, p. 91, uses it) | Not needed | Used only in the equivalence of 1.3. |

### 1.3 The two definitions of µ agree (my derivation)

Under the bilinear form x · y, which is nondegenerate, the subspaces V of dimension r correspond one to one with the subspaces L = V^⊥ of dimension n − r.

A subgroup Γ′ ⊆ Γ satisfies v · γ = 0 for all v ∈ V and γ ∈ Γ′ exactly when Γ′ ⊆ L. The largest such subgroup is Γ ∩ L. Hence l_r = max over subspaces L with dim L = n − r of rank(Γ ∩ L).

Also rank(Γ/(Γ ∩ L)) = l − rank(Γ ∩ L), because ranks add along the exact sequence 0 → Γ ∩ L → Γ → Γ/(Γ ∩ L) → 0. Put r = n − dim L, which runs over 1, …, n as L runs over the proper subspaces. Then Kerr's µ is min_r min_{dim L = n−r} (l − rank(Γ ∩ L))/r = min_r (l − l_r)/r, which is Masser's µ. ∎

### 1.4 Is Kerr's Lemma 6 true with arbitrary generators? (my derivation)

**Yes.** It follows from Masser's Proposition (§2, p. 83, checked against the page image) by rerunning his §5 proof with s generators in place of a basis. Masser's paper does not state this.

**Masser's Proposition (paraphrase).** Let E₁, …, E_h be commuting affine automorphisms of K[x₁, …, xₙ], and let 𝔐 be a proper maximal ideal. For 1 ≤ r ≤ n, let h_r be the largest rank of a stabilizer S(𝔓) ⊆ Z^h, as 𝔓 runs over the prime ideals of rank r contained in 𝔐. Suppose h_r < h for all r, and let N, D ≥ 1 be real numbers with N ≥ D^{η₁} + ⋯ + D^{ηₙ}, where η_r = r/(h − h_r). Then for any non-zero P of total degree at most D, some translate E₁^{n₁}⋯E_h^{n_h}P with 0 ≤ nᵢ ≤ N does not lie in 𝔐.

**The derivation.**
1. Take h = s and Eᵢ = translation by γᵢ (i = 1, …, s), with 𝔐 = (x₁, …, xₙ), exactly as on p. 90 but with generators instead of a basis.
2. Let φ: Z^s → Γ be φ(v) = Σ vᵢγᵢ. It is surjective, and its kernel has rank s − l. The translate E^v is translation by φ(v). So the stabilizer of a prime 𝔓 is S(𝔓) = φ⁻¹(Γ′), where Γ′ = {γ ∈ Γ : translation by γ fixes 𝔓}. Since ker φ ⊆ S(𝔓), rank S(𝔓) = rank Γ′ + (s − l).
3. Masser's proof of his inequality (10), on pp. 90 and 91, shows rank Γ′ ≤ l_r for every prime 𝔓 ⊆ 𝔐 of rank r. That argument uses only Γ′ and the prime 𝔓, not the choice of generators. Hence h_r ≤ l_r + (s − l), so h − h_r ≥ l − l_r.
4. If µ > 0, then l_r < l for all r, so h_r < h, and η_r = r/(h − h_r) ≤ r/(l − l_r) ≤ 1/µ. If F vanishes at every Σ mⱼγⱼ with 0 ≤ mⱼ ≤ M, all the translates vanish at the origin. The Proposition then forces M < D^{η₁} + ⋯ + D^{ηₙ} ≤ n D^{1/µ} (when M ≥ 1). With D = deg F this gives deg F > (M/n)^µ.
5. If µ = 0, the claim is deg F ≥ 1, which holds as in 1.2(d). ∎

### 1.5 Does Kerr's application satisfy Masser's hypotheses as stated?

**Yes, directly.**
- Γ = π(Z⁴) has rank 4. Lemma 7's proof shows π is injective on Z⁴, which holds when q ≠ 8 (Step 2, C.10).
- So γ₁, …, γ₄ are basis elements of Γ, and the points n₁γ₁ + ⋯ + n₄γ₄ with 0 ≤ nⱼ ≤ N − 1 are exactly Masser's Γ(N − 1).
- n = 3, and deg F ≥ 1 by 1.2(d). Masser's Theorem 1 applies as stated, with no need for 1.4.

### 1.6 Verdict on B22

- Kerr's Lemma 6 is **true**: it agrees with Masser's Theorem 1 for bases (1.3), and holds for generators by my derivation (1.4).
- The **citation does not cover it as written.** Masser assumes a basis. The generator form needs the extra argument of 1.4, which is not in Masser and not in Kerr.
- The **application is covered** by Theorem 1 exactly as Masser states it (1.5). The page does not say this, and does not point out that rank Γ = 4 is what makes γ₁, …, γ₄ a basis.
- There is no false step. B22 remains a break, and is **downgraded from substantive to routine**: the import that carries the argument is sound, and the gap is in how it is cited.

**Verdict on B4:** the source fully supports the lemma. The break is that the derivation, the second display, and the conductor fact are not on Kerr's page. B4 remains a break. It stays substantive because it is the analytic input of the whole argument, though the derivation is short (C.1).

## 3. Milne [4] against Kerr's Frobenius congruences (Step 2, items B7 and C.3)

### 3.1 Version and location

The ANTe6 file is **Milne, *Algebraic Number Theory*, Version 3.03 (May 29, 2011)**, typeset in a 327-page small-page format. In it, §8 "Global Fields" begins on p. 257. "The Frobenius element" is on p. 270, and Example 8.19 is on **p. 274**. **Arnoldo's images of pp. 274 and 275 come from this file.**

Kerr's reference gives no version, only "course notes, available online". The section number "§8" matches v3.03. I have not checked other versions, where the numbering could differ.

### 3.2 What Example 8.19 states

> Let K = Q[√d], and let p be a prime that is unramified in K. Identify Gal(K/Q) with {±1}. Then (p, K/Q) = +1 or −1 according as p does, or does not, split in K, i.e., according as d is, or is not, a square modulo p. Thus (p, K/Q) = (d/p).

The Frobenius element (pp. 270 and 271) is the unique σ in the decomposition group G(𝔓) with σα ≡ α^{N𝔭} modulo 𝔓 for all α in the ring of integers O_L, where 𝔓 is a prime of L unramified over 𝔭 and N𝔭 is the size of the residue field of 𝔭.

### 3.3 Does it support Kerr's congruences?

Kerr uses (√q)^p ≡ χ(p)√q and (√2)^p ≡ (2/p)√2 **modulo pO**, where O = Z[√q, √2]. Example 8.19 gives an element of the Galois group of Q(√d)/Q. Getting from it to Kerr's congruences takes four steps, none of them on Kerr's page or in Milne's example:

1. Apply the definition (pp. 270 and 271) to α = √d, for d = q and d = 2 separately. This gives (√d)^p ≡ (d/p)√d modulo each prime 𝔓 over p in O_{Q(√d)}.
2. Since p is unramified, pO_{Q(√d)} is the product of the distinct primes over it. So the congruence holds modulo pO_{Q(√d)}, hence modulo pO_K.
3. Pass from pO_K to pO. This needs p ∤ [O_K : O]. **My check:** the discriminant of the basis 1, √q, √2, √(2q) is (32q)², because the embedding matrix is the Kronecker product of [[1, √q], [1, −√q]] and [[1, √2], [1, −√2]], with determinant (−2√q)²(−2√2)² = 32q. So [O_K : O] divides 32|q|, and an odd p ∤ q does not divide it. Then O ∩ pO_K = pO: if x = py with y ∈ O_K, choose integers a, b with a[O_K : O] + bp = 1; then y = a([O_K : O]y) + bx ∈ O.
4. Identify Milne's Legendre symbol (d/p) with Kerr's Kronecker symbol χ(p) = (q/p) for odd p ∤ q.

**Verdict on B7:**
- The citation is **correct in substance but indirect.** Milne supports the Frobenius element, not the congruence modulo pO that Kerr writes.
- Bridging the two needs the four steps above, including a ring-index argument that Kerr never mentions.
- The direct route through Euler's criterion (my derivation C.3) takes one line and needs no Frobenius theory.
- B7 remains a routine break. There is no false step.

**Aside (Milne, not Kerr).** On p. 275 Milne's display reads (−1/p) = 1 if p ≡ 1 mod 4 and −1 if p ≡ 1 mod 4. The second case should read p ≡ 3 mod 4. This is a typographical error in the Application to quadratic reciprocity, which Kerr does not use. It does not affect Example 8.19.
