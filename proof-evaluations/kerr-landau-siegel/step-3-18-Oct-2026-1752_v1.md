### Check 4. The norm constant (Step 2 items B10, B17 and C.5)

c(\|q\|) = (1 + √2)(1 + √\|q\|)/√\|q\| has derivative −(1 + √2)/(2\|q\|^{3/2}) < 0. So its maximum over \|q\| ≥ 3 is at \|q\| = 3, where it equals **3.808** (exactly √3(1 + √2)(1 + √3)/3). Kerr's constant 8 holds with room to spare. Both ‖c_{ijk}‖ ≤ 8√\|q\| U in Lemma 3 and ‖θ_n‖ < B in Lemma 5 follow.

### Check 6. Margins and the two inequalities that carry the argument (Step 2 items B21, B28, C.8 and C.9)

**6a. Margin chain:** 5/4 < 13/10 < 4/3, with 13/10 − 5/4 = **1/20** and 4/3 − 13/10 = **1/30**. Exact.

**6b. "(9) implies (11)" made concrete.** Since ⌊i/p⌋ > i/p − 1, hypothesis (9) gives

  Σ E_p log p ≥ (13/10)(Σ i) log B − r θ(Q),

with no asymptotics needed. The script computes, exactly, the difference

  (13/10 Σ i − W) log(8N√3) − r θ(Q) − r log(32r√N),

where θ(Q) is the sum of log p over primes p ≤ Q. A positive difference means (11) holds for every 3 ≤ \|q\| ≤ N, that is, for every γ ≥ 1: the left side of (11) only grows with B, and the right side only grows with \|q\|.

| N | D | Q | difference / (W log B) | (11) holds |
|---|---|---|---|---|
| 100 | 52 | 2.5 | (Q < 3: Lemma 1 needs X ≥ 3) | n/a |
| 200 | 134 | 4.8 | 0.0114 | yes |
| 1,000 | 1,154 | 24.2 | 0.0305 | yes |
| 10,000 | 24,893 | 293 | 0.0368 | yes |
| 1,000,000 | 11,556,005 | 60,544 | 0.0390 | yes |
| 10,000,000 | 248,966,897 | 958,328 | 0.0393 | yes |

All 15 grid values from N = 200 to N = 10⁷ hold. The full table is in the output file. As N grows, the relative margin climbs toward the theoretical 0.04, since (1/20)/(5/4) = 1/25. This makes concrete what C.8 proves: the threshold N₀ is absolute and small.

Three limits on this check:
- It covers grid points only.
- The logarithms are double-precision values converted to exact fractions. The smallest margin, 1.1%, is far above rounding error.
- It does not replace the proof in C.8.

**6c. Order of choices in C.9.** With γ = ⌈90(C₁ + 2)⌉ and ε = 1/(160C₁γ), the bracket 1/30 − (1 + C₁ + 13/20)/γ − (16/9)C₁εγ is **at least 1/90**, computed exactly for C₁ ∈ {1/10, 1, 10, 1000}. The values run from 0.0111 to 0.0130. This confirms the arithmetic of C.9. It cannot confirm the value of C₁, which no source gives explicitly.

**6d. log Q.** log Q − (4/3)log N tracks −2 log log N, offset by the constant log(½) − (4/3)log 3 ≈ −2.16. This confirms Kerr's log Q = (4/3)log N + O(log log N).
